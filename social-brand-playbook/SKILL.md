# Social Brand Playbook

## Purpose
One durable source of truth for how the brand sounds and what each platform requires — and a grader checklist every draft must pass before it reaches a human for approval.

## Brand config (swap this block per brand)
- Brand name: [Your Brand]
- What we sell/do: [what you sell or do, in one line]
- Website: [yourbrand.com]
- Instagram: @[yourbrand] (business account); the bio holds the single tappable link
- Voice: [your voice — e.g. playful, warm, direct. Never preachy, never corporate.]
- Customer-facing creator/mascot name: [your public creator name] — internal names never appear in customer copy.
- Core hashtag: [your core hashtag — the one buyers actually search]

## Workflow
1. Load this skill at the start of any social drafting or review task.
2. Draft against the platform, audio, imagery, and copy rules below.
3. Score the draft with the grader checklist. Fix failures.
4. Return the score report (see Output Contract). A draft failing any hard check goes back for revision — it does not ship.
5. Stage passing drafts for human approval. Never auto-post; approval is always a human tap.

## Platform rules
Two buckets — get the bucket right and the rest follows.

**Bucket A — captions are NOT clickable (link in bio only): Instagram, TikTok**
- Never put a raw URL in the caption.
- Every Instagram caption ends with a link-in-bio CTA, e.g. "Tap the link in bio to start designing 👇".
- TikTok: same treatment — hook + hashtags, no URLs, link lives in bio.

**Bucket B — links ARE clickable (use direct URLs): Facebook, Threads, YouTube, Pinterest**
- Facebook / Threads: put the direct clickable URL in the post body.
- YouTube: direct URL in the video description (and channel links where relevant).
- Pinterest: attach the destination URL to the pin itself; title + description carry the hook.
- The phrase "link in bio" is only ever used on Bucket A platforms.

## Audio rule (video)
- NEVER publish a silent video. If audio cannot be attached or baked in properly, HOLD the video and report — do not ship it silent.
- Instagram / TikTok: use native trending audio via the phone app ("Use audio" at post time). Never bake trending audio into the upload file.
- YouTube / Facebook: baked-in licensed audio is fine.

## Imagery rules
- Photorealistic, real-product photography. Never a glossy AI-graphic look.
- Every image must depict something the shop can actually make, using processes it can actually run. Show real equipment and real processes.
- Banned: calling the material "genuine leather"/"real leather" when it is not (name the real material); showing products assembled in ways the shop doesn't assemble them; finishes the machines cannot reproduce; process imagery the real process doesn't create; rendering a machine doing something it doesn't do.

## Copy rules
- Sell the look. Never imply a production method the shop doesn't use.
- Every claim must be verifiable: prices, materials, and timelines come from a real source, never invented.
- Use the customer-facing names from Brand config.

## Grader checklist
Score each item pass/fail. Items 1–5 are hard fails: any fail blocks the draft.
1. **Link format:** correct bucket behavior (A: link-in-bio CTA present, no raw URL in caption; B: direct URL present and correct).
2. **Audio (video only):** audio attached or a concrete audio plan (named trending sound / licensed bed). Silent = fail.
3. **Imagery:** photorealistic; depicts only makeable products/processes; no banned depictions.
4. **Claims:** no false production or material claims; no invented prices, timelines, or specs.
5. **Names:** customer-facing names only; no internal names in copy.
6. **Voice (soft):** playful, warm, direct; matches brand energy. Flag misses as fixes, not blocks.
7. **Hashtags:** core hashtag present where the platform uses them.

## Output Contract
Every grading pass returns:
- Per-check pass/fail for checks 1–7
- Verdict: PASS (all hard checks pass) or FAIL
- Top 3 fixes, ordered by impact (hard fails first), each as a one-line concrete edit

## Operating Rules
1. Approval is always human. This skill stages drafts; it never posts, schedules, or publishes.
2. Hard checklist failures (1–5) block the draft. Do not reword around a violation and ship it anyway.
3. When a platform rule is ambiguous for a new format, default to the stricter bucket and flag it for the human.
4. Keep brand-specific values in Brand config only. The rules stay generic so the skill ports to other brands.
